# 🛒 Shopping Preference Predictor

A machine-learning web application that predicts whether a customer prefers **Online**, **In-Store**, or **Hybrid** shopping, built with Python, scikit-learn, and Streamlit.

---

## 📂 Project Structure

```
project/
├── app.py                  # Streamlit web application
├── train_model.py          # Dataset inspection, model training, model saving
├── requirements.txt        # Python dependencies
├── README.md               # This file
├── agent_instructions.md   # Notes for AI agents working on this project
├── .env.example            # Environment variable template
├── data/
│   └── dataset.csv         # Online vs Store Shopping Dataset (~11,789 rows)
└── models/
    └── model.pkl           # Saved sklearn Pipeline + metadata (generated by train_model.py)
```

## ⚙️ Local Setup

### 1. Clone the repository

```bash
git clone https://github.com/<your-username>/<your-repo>.git
cd <your-repo>
```

### 2. Create and activate a virtual environment (recommended)

```bash
python -m venv .venv
# Windows
.venv\Scripts\activate
# macOS / Linux
source .venv/bin/activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Train the model

```bash
python train_model.py
```

This will:
- Load `data/dataset.csv`
- Compare Logistic Regression, Random Forest, and Gradient Boosting via 5-fold CV
- Select the best model and evaluate on a held-out test set
- Save the trained pipeline to `models/model.pkl`

### 5. Run the Streamlit app

```bash
streamlit run app.py
```

Open **http://localhost:8501** in your browser.

## ☁️ Streamlit Community Cloud Deployment

1. Push your project to a **public GitHub repository**.
2. Make sure `models/model.pkl` is committed (or re-train on first run — see note below).
3. Go to [share.streamlit.io](https://share.streamlit.io) and click **"New app"**.
4. Select your repo, branch (`main`), and set **Main file path** to `app.py`.
5. Click **Deploy**.

> **Note on the model file:** `model.pkl` may be large. If it exceeds GitHub's 100 MB limit,
> add a startup script that runs `python train_model.py` before `streamlit run app.py`, or use
> [Git LFS](https://git-lfs.github.com/).

## 🧪 Model Details

| Candidate | CV Strategy |
|---|---|
| Logistic Regression | 5-fold, stratified |
| Random Forest (200 trees) | 5-fold, stratified |
| Gradient Boosting (200 estimators) | 5-fold, stratified |

The best model (by mean CV accuracy) is automatically selected, retrained on the full
training split, and evaluated on the 20 % held-out test set.
